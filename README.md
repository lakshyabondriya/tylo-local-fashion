# Stylo — Local Fashion Discovery Platform

Stylo is a real-time local fashion discovery platform that helps customers find nearby garment stores, browse available products, filter by size, color, brand and price, and reserve items for in-store trial or purchase.

## Key Features

- 📍 Nearby garment store discovery
- 🔎 Product search and filtering
- 👕 Product details and availability
- 🏪 Local store listings
- 📅 In-store item reservation
- 📱 Responsive, mobile-first interface

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser Geolocation API
- LocalStorage
